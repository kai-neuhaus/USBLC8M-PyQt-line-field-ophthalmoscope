# Line-field Ophthalmoscope with USB line camera 8M from Coptonix
## Background
This is some coarse coding for a research project to test a line-field ophthalmoscope design.

The code should work in principle and is here for reference.

Use at your own risk if you think you want to use it.

## Results of sorts
The project is currently not alive and the results were some early tests.

But it is actually a nice work including Zemax simulation and connecting up all the hardware.

The problems are a bit that the line-field illumination causes quite a few challenges to get a large field-of-view.
So there is still some thinking and research in progress.

The camera used was the https://coptonix.com/products/usb-line-camera-8m/
